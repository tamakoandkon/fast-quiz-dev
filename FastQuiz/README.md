## 题库

## 考试

### 试卷模板管理

管理员可进行增删改查

[x] 单个增改
[x] 批量删除
[x] 可以列表查看和单个详情查看

**发布考试/取消发布**
在之前的设计中这个操作被认定为是否可以生成题目快照，目前的架构重新设计后，只被标记为是否可以再次生成试卷快照，和试卷可见性的标志

[x] 已发布：可以生成试卷快照，可以动态生成试卷快照，名下的考试可以被用户看见，不可以删除和修改,抽题规则也无法修改

[x] 未发布：可以生成试卷快照，无法被用户看见，可以删除和修改，已开始或者已经结束的考试可以被看见，用户无法开始新的考试


### 试卷快照管理

根据抽题规则生成试卷快照

能浏览试卷快照的详情

管理员增加删除，不可修改
可以查看列表和单个详情

试卷模板发布后不可以新增和删除

_未来可能支持手动组卷_

### 试卷管理

根据试卷快照生成试卷

可以获取一个考试的所有试卷（管理员）
可以查看某个考生的所有考试（管理员）

可以获取自己的所有试卷

#### 答题记录

根据试卷id获取答题记录

答题记录中有题目快照信息，根据接口的不同，决定返回的内容是否带有答案

在试卷未交卷的时候，可以修改答题记录
